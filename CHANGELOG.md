# Changelog

## 1.0.0

Initial public release.

- Soft Dark and Invert modes
- Supports the RootsMagic 11 main window and separate top-level dialogs
- Keeps RootsMagic dark when focus moves to another application
- Global `Ctrl + Alt + D` toggle
- Optional **Start with Windows** tray setting
- Portable, no installer
- No network access
- No RootsMagic database or GEDCOM access
- No code injection
- No administrator rights required for normal use
- Single-instance protection
- Exact `RootsMagic.exe` process matching
- SHA-256 generation in GitHub Actions
