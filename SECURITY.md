# Security Policy

## Reporting a vulnerability

Prefer GitHub private vulnerability reporting if enabled. Do not post a suspected exploitable vulnerability publicly before it has been assessed.

## Security scope

RM Dark Helper is designed to:

- run locally
- avoid administrator privileges during normal use
- avoid network access
- avoid reading or modifying RootsMagic genealogy databases
- avoid code injection into RootsMagic

Release binaries should be built from the public source and accompanied by SHA-256 checksums.
