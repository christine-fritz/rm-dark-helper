# Privacy Policy

RM Dark Helper does not collect, store, transmit, or process personal data.

The application does not access the network and does not read RootsMagic genealogy databases, GEDCOM files, or genealogy content.

The only persistent system change it can make is creating or removing the current user's Windows Startup shortcut when the user explicitly enables or disables **Start with Windows**.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.
