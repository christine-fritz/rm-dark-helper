# Contributing

Issues and pull requests are welcome.

Please keep the tool small and dependency-light.

Do not add telemetry, network access, database access, or code injection without explicit discussion.

Before proposing a release, test:

- main RootsMagic window
- Edit Person
- at least one additional RootsMagic dialog
- minimize/restore
- switching to another application
- multiple open RootsMagic dialogs
- tray menu
- `Ctrl + Alt + D`
